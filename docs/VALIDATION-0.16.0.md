# Siril iPad 0.16.0 验证记录

## 操作与保存

图库选中图像 →「原版工具」→「曲线与表达式」。处理在iPad本地执行，导入原图保持不变，应用另存独立FITS。

曲线使用原版 `curve_transform`：三次/线性/Akima插值，RGB总曲线、R/G/B、Lab亮度/色度及饱和度，最多100个有序控制点，亮度范围和羽化。可点取、拖动、删除或数值编辑控制点，显示原版插值曲线及实际像素直方图；对数切换影响直方图计数，缩放/平移只影响图表。灰度图按原版只开放总曲线。最多保留30个阶段，每次从原图顺序重建；取色读取当前阶段之前的输入。范围蒙版预览不当作实际结果或附带源蒙版保存。

PixelMath直接使用原版表达式引擎：单RGB/灰度表达式、三条灰度输入表达式合成RGB，最多10个图像变量、参数表达式、输出重缩放和元数据累计选项。参考面板从上游函数/图像统计/运算符表提取65项，可在光标位置插入；此图像的表达式预设可保存/删除。参数、表达式和图像选择进入共享30步撤销/重做历史，跨关闭保存，随图库删除/恢复。

每次应用保存原参数、输入副本及 `advanced-tool.json`。`processing.ssf` 内的 `native_advanced` 是SirilPad桥接命令，调用上述原版内核；回放需要本App的命令接口及同目录参数文件，不是独立的桌面Siril命令。

## 新增科学校验

直接调用原版 `statistics(..., STATS_MAIN, ...)`，保留原版像素筛选、归一化和近似中值行为。
八项统计、归一化系数和像素数与独立读取同一 FITS 后调用原版函数的结果逐项比较，容差为 `1e-10`（双方均为 NaN 的未定义统计值按相同状态处理）。
测试覆盖整图、显示坐标选区、普通 RGB、未去马赛克 CFA、TOP-DOWN 图像，以及起点和尺寸为奇数的 CFA 选区。
另外以已知输入独立检查均值、平均偏差、MAD 和选中图像行，确认坐标转换没有把区域上下颠倒。

原版浮点中值使用直方图近似；四个样本 `{0.2, 0.3, 0.4, 0.5}` 的原版结果约为 `0.4`，并非精确排序中值 `0.35`。
移植保留该行为，测试不要求改成另一种中值算法。

直方图使用原版 `computeHisto` / `computeHisto_Selection`，将 65,536 桶合并为 512 个显示桶。
每个桶与独立原版调用的合并结果精确比较。整图与选区对零值及区间边界的不同处理按原版保留。
Swift 桥接校验包含 256×256 整图计数 65,536，以及 80×64 选区计数 5,120。

像素读数与完整 FITS 浮点数据逐通道核对，未使用缩小或拉伸后的显示图像。
文件头与原版存储的完整 UTF-8 文件头精确比较；短缓冲区不写入部分内容。
非法坐标、越界选区、非法通道和不合法统计桶数量均被拒绝。
缺失的温度/增益/偏置在 Swift 桥接中映射为缺失状态，界面显示“未记录”。

## 界面检查及限制

模拟器实际打开背景提取界面，以及统计、直方图、文件头三个分析标签，分别要求加载成功标记并生成截图。
截图检查确认图像、蓝色选区框、八项统计表、直方图曲线、原始文件头、原始像素读数和缺失元数据显示。
这些检查未通过合成触摸手势替代实机交互验证；iPad Air M4 的实际触摸、键盘输入、文件选择器和大幅真实相机图像仍待实机检查。

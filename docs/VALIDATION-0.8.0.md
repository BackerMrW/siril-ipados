# Siril iPad 0.8.0 验证记录

本轮接入原版 Drizzle / Bayer Drizzle；完整 Siril 移植仍未完成。
参数来自固定上游 `6c0f8f3207b9cb712f7e04249217123a8ca66915`，包括原版界面的像素比例范围 0.1–10、命令的输出倍率范围 0.1–3、六种核和主平场初始权重开关。

## 运行检查

- 四张有已知亚像素抖动的合成星场经原版两遍配准后实际应用 Drizzle。Point、Turbo、Square、Gaussian、Lanczos-2、Lanczos-3 均实际生成并叠加图像。
- 检查 2 倍输出尺寸、有限像素和亮星保留。读取每帧实际输出及权重文件，独立计算 `Σ(像素 × 权重) / Σ权重`，核对平均值和求和的原版 Drizzle 叠加结果。
- 将 Square 的像素比例由 1 改为 0.5，核对实际权重文件变化；没有以命令接受参数代替效果验证。
- Bayer 星场输出三个 RGB 通道，检查没有亮星的区域保持已知 R:G:B 背景比例。原版 Drizzle 像素值采用倍率平方的约定；测试关闭输出归一化，按该约定校验数值。
- Swift App 调用界面使用的脚本生成器和任务执行器，实际执行一遍 1 倍及两遍 2 倍 Bayer Drizzle；输入包含空间变化的平场及偏置。检查校准后的 RGB 背景符合 `天空背景 × 已扣偏置平场均值 × 倍率²`，输出不再带 Bayer 马赛克标记。
- 每次生成四个原版逐帧权重文件。删除并恢复整份任务后，权重字节保持一致；永久删除后相关路径消失。图库导入副本仍独立保留。
- 权重位深开关调用原版首选项；验证实际生成的 FITS 权重 BITPIX 为默认 8 位和匹配 32 位输出。
- 参数随任务保存，旧 0.7 JSON 缺少新增 Drizzle 键时仍保留原参考帧、倍率、两遍等设置。去马赛克、关闭配准、非有限像素比例及缺少主平场权重输入的无效配置被生成器拒绝。
- 在模拟器 App 中加载原生 Drizzle 页面，使用新鲜就绪标记并保存截图。既有校准、配准、叠加、背景、分析、删除恢复和图像撤销检查继续执行。

## 限制

这是受控小图和合成星场的验证；没有穷举全部核、倍率、像素比例、输出范围、剔除及权重组合。
真实相机大图、其他 Bayer 排列/偏移、物理 iPad Air M4 的触摸及内存表现需进一步验证。
畸变修正、外部参考、完整序列浏览和其他原版功能仍有缺口，详见完整功能核对表。

# Siril iPad 0.18.0 验证记录

接入原版反卷积／PSF单张工作流，工具入口累计38项；上游仍固定为 `2a724774dc4b2f9218d4d9055e81289b77ca9be3`。完整移植尚未完成。

## 参数、计算与保存

图库打开图像 → 原版工具 → 反卷积。40项参数保存到共享历史，按当前PSF／算法显示相关控件：Split Bregman、Richardson-Lucy乘法／梯度下降、Wiener；RL的TV／Hessian／无正则化、停止条件、步长、迭代与原版蒙版混合。

PSF支持原版Gaussian／Moffat／Disc／Airy，图像星点自动测量、ℓ0／Spectral Irregularity盲估计、多尺度及高级核参数，图库单通道／RGB PSF载入。Airy可从原版FITS解析结果读取焦距、口径和像元尺寸。已有核不跨输入默默复用；当前结果与实际使用的PSF独立保存并加入图库。仅生成PSF时只保存核文件，避免复制整张原图。参数和核选择支持30步跨关闭撤销／重做。

计算仍调用原版PSF生成器和 `generic_image_worker`／`op_desc_deconvolve`；保留其线程、取消、内存检查和蒙版混合。参数、输入副本、JSON和脚本保留，回放使用SirilPad的 `native_advanced` 扩展。图库与任务删除恢复保留独立结果／PSF；工作区释放原版核和会话预览。FFT频谱新增共享配对编号和默认相位选择，区分重复生成的同名文件。

## 独立回归

- 逐像素独立计算椭圆Gaussian与Moffat核；实际Disc／Airy核，PSF-only不改变源像素、不保存重复整图。
- 单位脉冲PSF：RL乘法无正则化保持已知RGB像素，Wiener输出按独立频率增益 `1/(1+1/500)` 比较；常量图像验证SB／RL固定点和Wiener增益。两种RL算法、三种正则化及停止条件均实际执行。
- 真实原版蒙版混合与独立像素加权比较；单通道核的RGB亮度路径、RGB核三通道保存／重读、保存的输入／参数／脚本回放均核对实际FITS。
- 已知Gaussian星点生成PSF，读取其实际宽度；仅添加焦距／像元元数据后核像素不变，原版解析后的光学数值正确。
- 实际ℓ0、SI和多尺度盲估计；96×96小图运行SI，覆盖此前原版150×150采样窗的越界。
- 零归一化核、黑图RL、没有星点的PSF估计明确失败，禁止导出旧结果。参数／核选择历史跨关闭撤销／重做；结果和PSF图库删除恢复逐字节一致、永久清理；原输入不变。
- 原有19条C回归和Swift校准／配准／Drizzle／叠加／背景／序列／存储事务、曲线／PixelMath、FFT、蒙版、格式往返继续通过。
- 原生反卷积结果和PSF-only两项界面真实计算后截图，方法／模型参数、实际结果／核和可用的应用按钮已按原始分辨率检查。

## 原版边界修复

1. RGB核保存中 `ndata` 已包含通道数，复制长度不再重复乘通道数，避免越界读取。
2. PSF生成／保存和SB／RL／Wiener的失败返回值向上交付，黑图RL不能把未处理像素报为成功。
3. SI高方差采样窗限制到实际图像大小，较大输入继续使用原版150像素窗。
4. 星点PSF生成使用原版拟合的像素FWHM，角秒宽度用于显示，避免焦距元数据改变像素核。

这些修复不替换原版反卷积、盲估计或PSF数学内核。

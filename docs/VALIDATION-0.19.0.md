# Siril iPad 0.19.0 验证记录

接续动态 PSF、孔径测光与序列差分光变；原版图像工具仍为38项。上游固定为 `2a724774dc4b2f9218d4d9055e81289b77ca9be3`。完整 Siril 移植仍未完成。

## 本轮工作流

- 图库图像 → 分析 → 动态 PSF 与测光：原版 Gaussian/Moffat 拟合、收敛精度、星点检测、ROI、CFA绿像素插值、RGB通道、固定/动态孔径和背景环参数。
- 星表提供排序、多选、平均PSF、删除、CSV、原版 `.lst` 和 FITS 表导出；星表与参数撤销/重做跨关闭保存，跟随源文件删除恢复。
- 所选星点 → 反卷积 PSF：遵循原版 `calculate_parameters` 的同通道/同模型/同单位检查，排除饱和星，使用像素FWHM与原版角度填入模型参数。实际核由已有原版Gaussian/Moffat生成器计算；参数进入工具历史，可以撤销、回放、预览、另存。不静默截断超出编辑器范围的测量值。
- 序列 → PSF、测光与光变：原版 `seqpsf` 与 `new_light_curve`，目标星/参考星选区、固定/跟踪/配准定位、参与帧、逐帧PSF和测光报告、差分星等与原版误差及曝光中点Julian时间。排除帧保留在报告中，标记为无测量。
- 原版光变引擎在各参考星单独通过80%有效帧规则、却没有同时有效帧时明确失败，避免进入零长度GSL绘图；相关临时缓冲区在失败与成功路径释放。

## 验证范围

- 独立已知椭圆Gaussian与Moffat中心、FWHM、beta、幅度和背景；像素宽度与角秒显示分开。
- 已知Gaussian积分通量对应的仪器星等、Poisson误差和SNR；固定/动态孔径、无效像素阈值与不完整背景环的失败状态。
- 原版检测ROI、RGB通道、CFA插值、三档收敛精度，以及非有限参数、越界选区与禁止覆盖已有导出文件。
- 所选星点的均值、饱和排除、原版生成的实际Gaussian核像素、参数编码回放、对称/自动核尺寸，以及全饱和/混合通道选择的原子失败。
- 已知三帧通量比独立验证差分星等 `-2.5 log10(factor)`，已知位移验证跟踪坐标，曝光中点时间验证；参与帧改变、配准缺失回退、报告与历史的删除恢复及永久清理。
- 旧19条C内核检查、38项原版工具、FFT、反卷积、曲线、PixelMath、蒙版、六种格式往返和完整Swift流程继续回归。
- 动态PSF及序列测光实际计算后的原生界面检查，与原有原生工作区检查一起运行。

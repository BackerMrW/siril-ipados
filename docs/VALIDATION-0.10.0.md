# Siril iPad 0.10.0 验证记录

本轮在序列工作区接入原版 `seqapplyreg`。完整 Siril 移植仍未完成，上游保持固定提交 `6c0f8f3207b9cb712f7e04249217123a8ca66915`。

## 新增检查

以下检查在最终 Swift 模拟器回归中全部通过：

- 四张有已知亚像素抖动的 Bayer 星场，排除中间帧并以第三帧为参考；原版两遍测量后，直接应用配准。检查输出三张真实 512×512 FITS、原文件编号为 1/3/4、输出参考帧索引正确映射；独立读取星点像素，从浮点存储数据定位唯一最亮星后比较输出质心，避免假定显示坐标与 FITS 行方向一致。
- 同一源序列再次应用后生成独立名称，旧输出与源图像字节不变；序列浏览可发现两次输出。原版参与标记显式以 `-filter-included` 传入。
- 重新包含之前未测量的帧时拒绝直接应用，撤销选择后恢复原参与集合；选择撤销历史不因应用输出而丢失。
- Bayer Drizzle 生成三张 RGB 输出、保存三张 32 位像素权重，记录选定主平场副本。独立解码浮点 FITS，以逐像素 Σ(输出×权重)/Σ权重计算期望，与原版叠加的三个通道像素比较；无覆盖像素检查为零，各通道同时检查足够数量的有效覆盖像素。
- 质量筛选不留下足够输出时必须报错，即使原版异步工作者的命令入口返回成功也不能把缺失的结果当作完成。
- 删除并恢复整份任务后，输出序列仍可读取，权重文件字节不变；永久删除移除所有任务输出与权重，不删除图库主平场。
- 模拟器加载原版测量/应用入口和 Drizzle 参数页，保存新鲜就绪报告与截图。以前的 C 内核、Swift 校准、Drizzle、背景、分析、存储与序列回归继续运行。

原版两遍分析自动更换参考帧。首次实际回归识别出界面指定参考帧未用于最终应用的问题；现在测量后、应用前通过原版 setref 恢复显式参考帧，序列与批处理均采用此流程，仍保留原版分析和矩阵算法。

## 参数与边界

应用界面接入原版四种输出范围、0.1–3 倍率、六种插值、钳位、六种 Drizzle 核、0.1–10 像素比例、主平场、默认 8 位或匹配输出的 32 位权重及质量条件。平场只用于本次 Drizzle 初始像素权重，不再次校准亮场。原版禁止的矩阵、传感器及插值/尺寸组合仍由原版检查。

输出独立命名并保留于所属任务。当前删除针对整份任务；单份配准输出的独立删除和像素结果撤销尚待接入。其他配准模式、畸变/外部参考、测光、序列背景提取和其他原版参数仍有缺口，详见功能核对表。

小型合成数据和模拟器检查不能代替物理 iPad Air M4、真实相机大图、多张照片内存和全部参数组合验证。

## 操作与数据

图库打开图像 →「原版工具」→「频谱」→正向变换；中心化默认与原版相同，也可使用常规顺序。原图、幅度谱、相位谱可比较。应用分别保存完整分辨率幅度／相位 FITS 并加入图库；幅度谱保留原图来源，用共享结果撤销恢复原图，相位谱作为独立图像保留。

逆变换打开幅度谱、选择图库中的配对相位谱。保留原版 DFTTYPE、DFTORD、逐通道 DFTNORM 元数据；类型、尺寸、通道、位深、顺序及有效归一化必须匹配。桌面 Siril 整数频谱使用原版 ushort 逆变换和舍入，空间结果再经原版转换器归一化到浮点工作区；浮点频谱直接使用原版 float 内核。

参数和相位选择进入共享30步跨关闭撤销／重做。应用保存输入副本、参数JSON和脚本。`native_advanced` 是 SirilPad 的桥接命令，回放需本 App 与同目录参数文件；数学计算使用原版 `fft_image_hook`／FFTW。导入双文件任一份损坏时回滚本次复制；图库删除／恢复／永久清理和任务整体删除／恢复保留实际文件。

## 回归范围

- 与 FFTW 独立的直接离散傅里叶计算：7×5奇数矩形、灰度／RGB、中心化／常规／全黑输入，逐像素幅度和有意义频率的相位比较；逆变换逐像素恢复原输入。
- 由原版命令生成16位整数频谱，再通过原生会话使用原版整数逆变换，验证恢复精度。
- 正／逆变换输入副本与JSON／脚本回放，实际重新读取FITS；幅度谱的类型、顺序和归一化保留，空间结果去除频谱类型／顺序。
- 非PHASE文件、普通输入、顺序不匹配与失败后的旧结果导出被拒绝；损坏结果导入不残留相位副本。
- 相位选择参数历史撤销／重做跨关闭保存；实际双文件导入、图库删除恢复逐字节一致、永久清理；任务删除恢复后的相位字节一致。原输入和配对频谱不被覆盖。
- 原有校准／配准／Drizzle／叠加／背景／存储事务、曲线／PixelMath、蒙版、格式往返和工作区回归继续执行。
- 原生 FFT 幅度、相位、逆变换选择界面分别执行真实计算后截图，应用按钮可用。

## 边界适配

FFT仍使用原版FFTW正／逆向函数。全黑频谱归一化避免0/0，DFTNORM保留真实0；原版DFT信息 helper 正确向当前拥有的图像复制type／ord／norm，不写另一份全局图像。整数输入的32位输出模式不自动转换load缓冲，因此桥接入口用原版转换器提升其临时图像；整数频谱逆向仍读取原始位深调用整数内核。按剩余内存检查工作缓冲；中止或失败不能应用旧结果。

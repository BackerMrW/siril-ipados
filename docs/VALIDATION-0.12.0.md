# Siril iPad 0.12.0 验证记录

本轮接入原版序列背景提取。固定上游 `569e699ce0d19c00d383fd1930a87096aa34b4f9`；完整 Siril 移植仍未完成。

## 原版流程与参数

直接调用 `apply_background_extraction_to_sequence`，保留原版序列 worker、逐帧采样、CFA 四子通道处理和自动模型；不是复制单张手动坐标。原版 `seqsubsky` 对采样模型不开放除法，因此使用原版 GUI 接口保留减法/除法。预览通过同一翻译单元导出原版静态序列 image hook，算法没有替换。

共享单张与序列模型控件：RBF、1–4阶多项式、平滑度、减法/除法、抖动，以及自动模型的尺度、平滑、结构保护、阈值/范围、预先多项式与1/2/4/8降采样。序列另外接入采样数、容差、随机暗区、暗区优化、像素/百分比边缘排除。参数30步撤销/重做跨关闭保存，滑块一次拖动合并一步，新修改清除重做分支。

## 像素与保存验证

- 单色、RGB、Bayer 三组256×256真实 FITS、不同帧梯度/亮度和恒星；原版序列采样多项式/RBF、减法/除法、自动与简化自动模型。
- 预览与真实序列输出逐像素比较；原版命令支持的模式另与 `seqsubsky` 输出逐像素比较。检查有限像素、梯度减弱、恒星保留、参与帧原编号以及未改变的源标志。
- 随机/暗区优化/抖动/边缘选项运行；重复前缀、非法路径前缀和 NaN 参数拒绝，避免原版 prepare hook 清理旧结果。
- Swift从真实序列建立背景任务：排除中间帧、显式参考帧映射、输出数量/像素、重复独立输出、原 FITS 和原索引字节不变、预览输出对应；参数撤销/重做/分支/30步上限。
- 全零坏帧触发原版跳过帧行为，Swift 检查实际输出数量并拒绝部分成功；失败的完整参数、源序列快照、日志与状态保留。
- 源参与选择撤销不受背景处理影响；整个任务移入最近删除、恢复和永久删除，验证校正 FITS、旧输出与参数历史。
- 保留已有内核/Swift 校准、配准、Drizzle、叠加、背景编辑、分析、存储回归；原生序列背景页加载实际帧和同一序列 hook 校正预览后截图。

## 范围

校正输出按原版生成普通序列，不继承 Drizzle 权重；原 Drizzle 序列和权重保留，建议在 Drizzle 前校正。随机采样或抖动会导致独立预览与整组处理有随机差异。背景模型视图按原版对话框由原图与校正结果重建，是显示用途。

目前支持整任务删除/恢复；单份背景输出独立删除、结果切换撤销、蒙版与其他原版工具仍待接入。物理 iPad Air M4、真实相机大图、文件选择和全部手势组合仍需真机验证。

# Siril iPad 0.9.0 验证记录

本轮接入原版序列工作区；完整 Siril 移植仍未完成。固定上游提交保持 `6c0f8f3207b9cb712f7e04249217123a8ca66915`。

## 验证范围

- C 接口调用原版 `readseqfile`、`seq_check_basic_data`、`seq_read_frame` 和 `writeseqfile`。质量字段与独立原版读取逐项比较，包含 FWHM、加权 FWHM、圆度、背景、星数及矩阵平移，不以替代算法生成质量值。
- 确认原版帧图像的尺寸、原始像素和显示方向；拒绝非法路径、通道、容量、帧索引和排除的参考帧。独立图像句柄在关闭命令工作区后仍有效。
- 三张已知亮度的 FITS：全部帧叠加与排除高亮帧后的结果分别匹配独立的均值预期；恢复包含后再次匹配原值。排除不改变输入像素。原版 stack 默认忽略参与标记，重新叠加显式传入 `-filter-included`；数值回归实际识别并防止这个错误。
- Swift 实际建立序列、重新叠加、用新 actor 恢复持久化撤销/重做、验证新修改清除重做分支；序列写入中断后恢复文件字节和历史。
- 原版 `seqstat` 保存统计并导出表格；质量 CSV 包含参与/参考帧和归一化统计。运行中的任务不允许同时访问/编辑。
- 重新叠加保存新结果且旧结果字节不变，任务记录可找到全部输出；删除/恢复任务保留序列选择和结果，永久删除释放任务文件。
- 合成星场经过真实两遍配准，保存原版质量数据；模拟器加载帧预览与质量图，使用新鲜就绪标记并保存截图。原有 Drizzle、批处理、背景、分析、删除恢复等回归继续执行。

## 限制

验证使用受控小图和合成星场。物理 iPad Air M4 的触摸、多张真实相机大图和内存表现仍需实机验证。
序列工作区中的两遍配准按钮测量质量和矩阵；需应用旋转/缩放/Drizzle 时，仍从批处理生成相应输出序列再打开它。图中的质量通道与原版叠加自行选择的配准层不是同一设置。
测光、其他配准模式、背景对整个序列应用、其他原版交互和参数仍有缺口，详见功能核对表。

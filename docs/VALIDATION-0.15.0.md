# Siril iPad 0.15.0 验证记录

本轮接入33项原版单张工具、共用蒙版与PNG/JPEG/TIFF原版读写。固定上游为 `2a724774dc4b2f9218d4d9055e81289b77ca9be3`，完整 Siril 移植尚未完成。

## 操作与数据

图库选中图像 →「原版工具」。工具提供完整分辨率计算、原图/结果/蒙版预览、RGB通道、缩放与独立结果另存。修改参数会废弃旧计算；失败后旧预览不能应用。参数最多30步撤销/重做，关闭后继续保留；应用结果使用已有图库结果历史。

支持亮度、通道、外部图像、颜色和星点蒙版，以及阈值、模糊、羽化、反转和乘法。星点蒙版使用指定通道的原版检测结果；没有检测结果时报错。蒙版存为结果FITS旁的 `.mask.fits`，重新导入后可在下一次处理继承；几何工具可变换继承的蒙版。参数 `.tools.json` 和蒙版随图库删除/恢复/永久清理一起处理。

图库导入PNG/JPEG/TIFF时，调用原版解码并转换为独立浮点FITS，保留外部原文件。选中图像 →「导出图片」支持8/16位PNG、JPEG质量和8/16/32位TIFF；显示自动拉伸不写入导出像素，需要先应用拉伸。输入副本和导出文件保存在对应任务，任务永久清理释放存储。

## 回归范围

- 所有33项工具执行原版worker，输出有限RGB像素且输入FITS逐字节保持不变。对负片、MTF、SCNR、非中心裁剪、镜像、两方向直角旋转、合并像素和独立宽高最近邻重采样使用独立像素预期；任意角度旋转执行真实插值。
- 零度旋转和原尺寸重采样保留像素；负角度方向正确。不同ROWORDER传感器标签下裁剪同一显示位置；巨大输出在分配前拒绝。
- 原版全部五种蒙版来源；RGB各通道星点位置不同，验证指定红通道星点及无星背景，防止静默使用绿色通道。8/16/32位通道蒙版的独立精度、真实负片混合与反转；外部引导图和零调制像素保留。
- 阈值/模糊/羽化/强度，蒙版导出重新导入、原尺寸继承和重采样后尺寸；无效参数和失败计算废弃旧预览。
- 持久参数撤销/重做与新分支；图库删除恢复后参数和蒙版逐字节一致，永久清理删除全部附带文件。
- 六种原版导出格式往返，完整RGB尺寸与方向，按位深检查像素精度；JPEG按有损容差检查。拒绝覆盖，非法JPEG/PNG/TIFF报错而不终止App。
- 原有19条C内核数值回归，以及Swift校准/配准/叠加/Drizzle/背景/序列历史/存储事务全部继续运行。真实原生GHS、蒙版、滤镜和几何界面计算后截图。

## 移动适配修复

原版亮度蒙版命令误绑定到通道解析器，修正为原版亮度函数。双边滤波历史字符串超出原固定栈缓冲区，改为动态字符串。单张无界面星点检测按原版锁管理结果并在关闭图像时释放。几何命令补齐桌面界面允许的零度、负角度、原尺寸、百分比范围和独立宽高，计算前检查可用内存。蒙版导出修正单通道FITS维度；整数格式解码后通过原版按位深归一化转换进入浮点接口；JPEG读取保留原像素算法，增加错误恢复、文件生命周期和组件布局检查。

## 限制

33个工具工作区不等于全部Siril界面和参数都已移植。处理ROI、多边形/手绘蒙版、所有原版GUI细节和序列工具仍有缺口；曲线、像素数学、FFT/反卷积、天文颜色校准、解算、PSF/测光、剩余配准模式、RAW/HEIF/JXL/XISF/视频和桌面扩展仍需实现与专项验收。CMYK JPEG不支持；TIFF高级压缩/色彩管理选项未全部开放。物理iPad Air M4、触摸、大型真实相机数据和侧载签名保留数据尚未在本轮验证。

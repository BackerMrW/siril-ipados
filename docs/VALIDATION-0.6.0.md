# Siril iPad 0.6.0 验证记录

此版本增加删除、恢复、空间清理及单张处理结果撤销/重做；未宣称完整桌面功能已移植。

## 本次检查

- 图库批量移入最近删除，库索引同步移除；原始导入来源不被删除。
- 模拟恢复两张图像时只移动第一张就中断，重新读取日志后恢复库索引，剩余图像仍可恢复。
- 恢复后 UUID、帧类型、父图像关系保持不变，两份 FITS 内容逐字节一致。
- 永久清空后文件不再存在、图库字节数减少、最近删除文件字节数为零。
- 删除整个任务包含输入副本、中间文件、脚本和日志；恢复后输入副本存在；图库副本不受影响。
- 标记运行中的任务拒绝删除；图库中的符号链接拒绝删除，外部原始文件仍存在。
- 单张结果撤销/重做定位到对应完整 FITS；历史可保存和重新读取；开启新处理链清空重做分支。
- 原版内核释放命令工作区图像与序列状态后，独立图像会话的原始像素仍相同；再次运行原版命令成功。
- 加载真实 SwiftUI 图像工作区及删除与存储界面，检查新鲜就绪标记并捕获截图。
- 继续运行既有原版科学计算检查，以及背景提取、统计、直方图和文件头三种分析界面检查。

自动检查运行在 macOS 的 iPad 模拟器；不替代真机触摸操作验证。
图库、任务和最近删除统计的是文件大小；实际系统可用存储变化受文件系统分配及系统统计刷新影响。

## 删除与撤销的范围

图像左滑或长按可删除；选择菜单可以删除勾选图像。移入最近删除不复制文件，仍占存储。
“删除与存储”中可以恢复、永久删除或清空。永久删除不能撤销，也不会自动定期清空。
任务记录左滑或长按可删除整个任务。导入图库的结果副本与任务目录独立，需要分别清理。
删除正在显示的图库图像会清除预览、活动文件和选区，并清理无效重做记录。

撤销/重做适用于本版本生成并打开的单张处理结果，包括背景校正。
原图与结果各自保存，恢复的是文件中的真实像素与文件头，而非仅改变显示拉伸。
旧版结果、从外部导入的结果、历史记录中重新导入的结果，没有可靠父图像记录，不能补出撤销链。
采样点/参数编辑、序列/叠加、多边形/ROI/蒙版的统一撤销仍待移植。

# Siril iPad 0.14.0 验证记录

本轮接入整组序列处理结果撤销与重做，仍使用原版 Siril 内核；固定上游 `2a724774dc4b2f9218d4d9055e81289b77ca9be3`。完整 Siril 移植尚未完成。

## 行为

入口：序列工作区顶部「处理结果撤销」。配准输出立即切换，背景校正输出在关闭校正页后切换。按钮恢复真实序列、当前图像尺寸和 RGB/灰度通道，重新读取帧与参与选择；保留旧 FITS 和 Drizzle 权重，没有复制或覆盖像素。帧勾选/参考帧使用独立的「撤销参与选择」。

历史按入口保存在任务 `SequenceResults` 内，最多30步，跨关闭继续。打开已有输出时沿保存的来源元数据建立前序链；重复从固定输入应用得到兄弟输出。撤销后新处理清除重做分支，旧输出仍在管理页。当前输出被删除时回到可用前序，缺失步骤保留在重做链；恢复输出后重做可用。整任务删除/恢复包含历史，读取已删除任务不会重新创建同名空目录。

## 回归范围

- 真实256像素单色输入、512像素RGB Drizzle和原版背景 worker 输出；撤销/重做核对原版读取的尺寸、通道和像素。
- 新 actor 重读持久历史；重复完成通知不增加步骤；同一输入的重复应用不伪造串行链。
- 由背景输出来源重建两步历史，两方向同时可用；打开输出本身也能找到来源。
- 新分支清除重做，之前的索引、FITS、缓存与权重逐字节保持不变。
- 当前背景输出单独删除后自动回退、重做禁用；恢复后重做返回相同像素。
- 运行中任务、跨任务引用、保存历史中的路径穿越、未验证完成的输出被拒绝，结果游标不受失败操作影响。
- 整任务删除后历史读取失败且不创建任务目录；恢复后的当前输出和撤销/重做仍可用，原权重保持不变。
- 原生工作区在真实背景校正结果撤销后显示RGB Drizzle帧以及可用的撤销和重做按钮并截图。
- 继续运行原有校准、配准、加权叠加、背景、编辑历史、独立输出事务与空间清理回归。

## 限制

只将完整验证、有来源记录的序列处理输出加入历史。旧版本没有来源记录时无法可靠重建全部链。历史保留文件，实际释放空间仍需永久删除；被永久清理的历史步骤无法恢复。叠加结果切换与蒙版撤销，以及功能核对表中的其他缺口仍待接入。物理 iPad Air M4、真机触摸和真实相机大图尚未验证。

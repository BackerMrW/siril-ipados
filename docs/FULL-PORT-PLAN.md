## 持续约束

1. 先实现并测试共用能力，再将工具接入；按钮不得调用空实现。
2. 优先调用原版图像/序列worker。原版命令遗漏GUI能力时补桥接，而不是删参数或用另一套算法替代。
3. 来源、设置、日志与输出保留；原图不可覆盖。删除到最近删除后仍可恢复，永久删除释放真实存储。
4. 参数修改废弃旧模型；失败或中止不得报成功，预览未完成时不可应用。
5. 后续实现仍检查 `FUNCTIONAL-PARITY.md` 和原版代码；只有通过对应验收的项目才能改为完成。
6. 外部程序、可选依赖、移动模型和实际设备限制必须明确记录，不以“内核已经编译”代替完整原生移植。

本轮受测与已实现工作包的证据见[0.15验证记录](VALIDATION-0.15.0.md)。其他工作包保持待实现/待验收，不计入完整移植。

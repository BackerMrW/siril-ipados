## 后续固定收尾顺序

当前只收尾参与帧平均倾斜：普通/FITSEQ/SER 的数值、来源保护、取消/失败恢复及实际页面全部通过后，才进入下一批。现有已通过的功能不因等待构建而追加无关优化。

1. 剩余序列工具与配准：完整序列应用、畸变/外部参考、其余输入和参数组合；按原版工作器核对实际输出。
2. 天文分析：天球网格/星表标注、标准星/绝对测光及完整测光流程、实际远程星表端到端。已有 WCS 畸变显示已通过，完整畸变解算仍在上一批范围内。
3. 工作区交互：多边形/自由绘制、剖面、完整比较和直方图叠加、文件信息编辑及剩余原版动作。
4. 平台与扩展：Python/插件、StarNet 等外部模块的实际移动实现和后台生命周期。明确不可直接运行桌面可执行文件的部分，不能用空入口替代。
5. 安装和真机：签名安装、物理 iPad 上的大型相机数据、触摸、内存、长视频和后台/取消。SDK 设备目标构建通过不能替代此项。

每一批以实现、对应数值/文件保护检查、实际原生流程和证据记录为完成条件。整个移植只有在上述缺口及核对表中的剩余项全部处理、必要验收通过后才可标记完成；当前仍未完成。

## 持续约束

1. 先实现并测试共用能力，再将工具接入；按钮不得调用空实现。
2. 优先调用原版图像/序列worker。原版命令遗漏GUI能力时补桥接，而不是删参数或用另一套算法替代。
3. 来源、设置、日志与输出保留；原图不可覆盖。删除到最近删除后仍可恢复，永久删除释放真实存储。
4. 参数修改废弃旧模型；失败或中止不得报成功，预览未完成时不可应用。
5. 后续实现仍检查 `FUNCTIONAL-PARITY.md` 和原版代码；只有通过对应验收的项目才能改为完成。
6. 外部程序、可选依赖、移动模型和实际设备限制必须明确记录，不以“内核已经编译”代替完整原生移植。
